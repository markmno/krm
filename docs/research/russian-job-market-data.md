> Синтезировано из 4 параллельных расследований librarian-агентов,

## Краткое резюме

**Основной источник:** HH.ru API — доминирующая российская платформа вакансий (80%+ рынка). Требуется живой сбор.

**Ключевой вывод:** Крупных, чистых, готовых датасетов HH.ru по естественно-научным специальностям не существует. Необходим самостоятельный сбор через API. Для доступа к HH.ru API обязательна OAuth2-авторизация (https://dev.hh.ru).

## HH.ru (HeadHunter) API

### Детали API

| Атрибут | Значение |
|-----------|-------|
| **Базовый URL** | `https://api.hh.ru` |
| **Эндпоинт поиска** | `GET /vacancies` |
| **Эндпоинт деталей** | `GET /vacancies/{id}` |
| **Авторизация** | OAuth2 обязательна (403 на анонимных запросах с 2025+) |
| **Регистрация** | https://dev.hh.ru |
| **Ограничение скорости** | ~2–3 запроса/сек (недокументировано, эмпирически) |
| **Максимум результатов на поиск** | 2,000 (20 страниц × 100 per_page) |
| **Обязательные заголовки** | `User-Agent` с идентифицирующим именем |

### Ключевые параметры API

```
GET /vacancies?
  text=физик              # Поисковый запрос (нечёткое совпадение)
  &area=113               # ID региона: 113=Россия, 1=Москва, 2=СПб
  &professional_role=100  # Фильтр по проф. роли (100=Наука/Образование)
  &per_page=100           # Результатов на страницу (макс 100)
  &page=0                 # Номер страницы (с нуля)
  &only_with_salary=true  # Только вакансии с зарплатой
```

### Professional Role ID

| ID | Категория |
|----|----------|
| 96 | Производство, сервисное обслуживание |
| 100 | Наука, образование |
| 101 | Информационные технологии |
| 102 | Медицина, фармацевтика |
| 103 | Строительство, недвижимость |
| 104 | Административный персонал |
| 112 | Рабочий персонал |
| 116 | Добыча сырья |

## Альтернативные источники данных

### Трудвсем.рф (Работа России) — государственный портал

| Атрибут | Значение |
|-----------|-------|
| **Тип** | Государственный портал занятости |
| **API** | Open Data API (REST), авторизация НЕ требуется |
| **Формат** | JSON API + пакетные CSV-датасеты |
| **Масштаб** | 5M записей безработицы, 18M записей пособий |
| **Качество** | Ниже, чем HH.ru; преимущественно низкоквалифицированные вакансии |
| **Ценность для нас** | Источник кросс-валидации; государственные научные позиции |
| **URL** | https://trudvsem.ru/opendata |

**Потенциал реализации:** Использовать Трудвсем как вторичный источник для проверки и обнаружения позиций, которые HH.ru может пропускать. Государственные НИИ часто публикуют вакансии здесь.

### SuperJob API

| Атрибут | Значение |
|-----------|-------|
| **API** | REST API v2.0, полный OAuth2 |
| **Ограничение скорости** | 120 запросов/минуту (щедро) |
| **Охват** | Вторая по величине российская доска вакансий |
| **Сильная сторона** | Больше инженерных/промышленных вакансий, чем на HH.ru |
| **URL** | https://api.superjob.ru |

**Потенциал реализации:** Будущее расширение. SuperJob лучше покрывает промышленные инженерные позиции (производство, энергетика, строительство), где HH.ru слабее.

### Zarplata.ru и Rabota.ru

Публичные API отсутствуют. Автоматизированный сбор невозможен.

## Исторические архивы

### Wayback Machine (Internet Archive)

- Поисковые страницы HH.ru архивированы с 2018 по настоящее время
- Каждый снапшот архива включает количество вакансий по специализациям
- Можно восстановить: «Сколько вакансий физиков в 2019 против 2025?»
- Методология: Парсинг заархивированных страниц результатов поиска для извлечения количества вакансий
- **Ценность:** Анализ трендов — рост/сжатие рынка по специальностям

### Стратегия сбора данных

```
Основной:     HH.ru API (живой)            → 80% данных
Вторичный:    Трудвсем Открытые данные     → кросс-валидация
Архивный:     Wayback Machine              → исторические тренды (опционально)
Будущий:      SuperJob API                 → инженерное покрытие
```

## Качество данных: известные проблемы

### Известные проблемы данных HH.ru

1. **Несогласованные названия должностей:** «Научный сотрудник», «Researcher», «R&D Scientist», «Физик-исследователь» — одна роль, разные названия
2. **Дубликаты вакансий:** Одна и та же вакансия перепубликуется в разных городах/у разных работодателей
3. **Отсутствие данных о зарплате:** ~40% вакансий не содержат информации о зарплате
4. **Шаблонные описания:** Некоторые работодатели используют типовые описания без реальных требований к навыкам
5. **Смешанный язык:** Вакансии содержат и русские, и английские термины («Python разработчик», «MATLAB modeling»)
6. **Нечёткий поиск:** Поиск HH.ru намеренно нечёткий — возвращает слабо релевантные результаты

### Стратегия смягчения

1. **Дедупликация:** Хеш-дедупликация по ID вакансии + порог схожести содержания
2. **Обработка зарплат:** Раздельный анализ вакансий с указанием зарплаты и без
3. **Обнаружение шаблонов:** NLP-эвристика для типовых описаний (низкое лексическое разнообразие)
4. **Обработка языка:** Единообразная лемматизация и русских, и английских терминов
5. **Точность поиска:** Поиск API для полноты (recall), NLP-фильтрация по ключевым словам для точности (precision)
